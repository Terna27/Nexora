# Cryptiq Mobile Application

Native React Native & Expo application for the Cryptiq digital asset investment platform.

## Features
- **Native Implementation**: Built with React Native and Expo Router (no WebViews).
- **Mobile-Adapted Robotic Arachnid Scanner**: A lightweight, battery-efficient adaptation of the signature procedural crawler that respects device battery life and accessibility reduced-motion settings.
- **Interactive 3% Scenario Calculator**: Non-compounded illustrative scenario projections with prominent risk disclosures.
- **Supported Assets & Custody Overview**: Real-time view of assets, liquidity tiers, and security architecture.
- **Authentication Flows**: Institutional login and onboarding interfaces.

## Running Locally
```bash
# Start Expo development server
pnpm --filter @cryptiq/mobile start
```
