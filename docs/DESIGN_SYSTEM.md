## 2. Typography

- **JetBrains Mono / IBM Plex Mono**: Transaction hashes, telemetry values, latency readouts, and terminal tables.
- **Inter / Modern Sans**: High-impact headlines, body descriptions, and navigational links.

---

## 3. Crawler Engine Inverse Kinematics Specs

- **Chassis**: Hexagonal angular armor with glowing reactor core.
- **Leg Geometry**: 8 limbs (4 left, 4 right).
- **Leg Segments**: Coxa ($16\text{px}$), Femur ($26\text{px}$), Tibia ($32\text{px}$).
- **Kinematics**: 2-bone analytical law-of-cosines inverse kinematics with outward elbow flexion.
- **Gait**: Ripple tetrapod gait ($[0, \pi, \pi/2, 3\pi/2]$ phase distribution) avoiding unnatural synchronous hops.
